# Recovery record

Date: 2026-08-13

The original uncommitted source directory was lost. The surviving project was
temporarily moved to Trash and restored in this repository; no separate Trash
backup is present.

The original Codex conversation that created and ran the project is retained
locally but is not included in this public repository.

This project is a filesystem recovery, not a Git checkout. It contains the fixed
protocol, fixtures, runner, scoring scripts, the 12 primary raw runs, four
supplemental retry artifacts, metadata, and disposable workspaces. Raw runs
were not rewritten. The new `benchmark/` directory is separate from the
historical pilot.

Some historical raw `run.json` records retain absolute prompt paths from before
the recovery. Those records are immutable provenance; current scripts use
repository-relative paths.

## Known condition

- Flash arm: `inclusionai/ling-3.0-flash` through OpenRouter, Elpis binary
  SHA-256 recorded in every run.
- Tiny arm: not run; no configured serving path was available.
- All primary wrapper processes ended under the PTY timeout boundary, so wrapper
  exit status is infrastructure evidence, not a model pass/fail score.
- `exact_contract`: expected JSON is present in all 3 raw transcripts.
- `long_context`: exact artifact and scope pass in 2/3 workspaces; repetition 3
  has no artifact.
- `tool_sequence`: exact artifact and scope pass in 2/3 workspaces; repetition
  3 has no artifact.
- `code_scope`: repetitions 1 and 2 changed only the intended source behavior
  and report `PASS` in the transcript; their historical workspaces also contain
  generated bytecode because the fixture lacked `.gitignore` at run time.
  Repetition 3 has no source change and no artifact.

## Supplemental continuation

- `code_scope__r04` is a valid supplemental pass by workspace score, but its
  interrupted launcher did not retain `run.json`.
- `code_scope__r05` is a fully recorded supplemental pass using the
  completion-aware monitor.
- `long_context__r04` and `tool_sequence__r04` reached the provider and then
  recorded `Stream disconnected before completion`; neither created an
  artifact.

The evidence supports a bounded Flash/Elpis compatibility observation. It does
not support a general model ranking, a Tiny result, production readiness, or an
Elpis causal-performance claim.
